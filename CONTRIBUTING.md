# Contribuir al Proyecto

¡Gracias por tu interés en mejorar esta herramienta! Aceptamos contribuciones para mejorar la precisión de la conversión JATS, optimizar el rendimiento o añadir nuevas características a la interfaz.

## Cómo Contribuir

1. **Reportar Problemas**: Si encuentras un bug o tienes una idea para una mejora, abre un "Issue" describiendo el problema detalladamente.
2. **Enviar Cambios (Pull Requests)**:
    - Haz un Fork del repositorio.
    - Crea una rama para tu feature (`git checkout -b feature/nueva-funcionalidad`).
    - Haz tus cambios y asegúrate de que el código siga las convenciones existentes (PEP 8 para Python).
    - Envía un Pull Request describiendo tus cambios.

## Estilo de Código

- Usamos **snake_case** para funciones y variables.
- Añade **docstrings** a las nuevas funciones explicando sus argumentos y retorno.
- Si modificas la lógica de validación, asegúrate de probar con múltiples archivos XML válidos e inválidos.
